## **HTML Basics**

*What is an HTML attribute?*

-Extra information added to an HTML element

-Written inside the opening tag

Example: href, src, class



**Anatomy of an HTML Element**

Opening tag — <p>

Content — the text or image

Closing tag — </p>

Example:

<p>Hello world</p>


Difference Between <article> and <section>

<article> — standalone content that could exist on its own (blog post, news item)

<section> — groups related content within a page



### **Typical Website Elements**

<header> — top of the page

<nav> — navigation links

<main> — main content

<section> / <article> — content areas

<footer> — bottom of the page



### **Metadata & SEO**

***How Metadata Influences SEO***

-Helps search engines understand the page

-Improves how pages appear in search results

-How the <meta> Tag Is Used

-Placed inside <head>

-Provides info like description, author, or viewport

Example:

<meta name="description" content="My personal website">



### **Website Design**

***First Step to Designing a Website***

-Define the purpose of the site

-Most Important Question to Answer

-Who is this website for and what should it do?



### **Semantics**

Why Use <h1> Instead of <span> for a Heading

<h1> tells browsers and screen readers it’s a main heading

<span> has no meaning by itself



  *Benefits of ***Semantic Tags***

  *Better accessibility

  *Better SEO

  *Code is easier to read and understand
  ### **JavaScript**

***A programming language that makes websites interactive**

2 Things That Require JavaScript

  *Button clicks and alerts

  *Form validation or dynamic content updates


**How to Add JavaScript to HTML**

Using a <script> tag

Linking an external .js file

Example:
