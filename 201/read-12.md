## Canvas

### What does the **canvas** allow a developer to achieve?
The `<canvas>` element allows developers to draw graphics directly in the browser using JavaScript. It can be used to create drawings, animations, games, and visual data like charts.

### What is the importance of the closing `</canvas>` tag?
The closing `</canvas>` tag defines the end of the canvas element. Any content placed between `<canvas>` and `</canvas>` can act as fallback content for browsers that do not support the canvas element.

### Explain what the `getContext()` method does.
The `getContext()` method is used to get the drawing environment of the canvas. For example, `getContext("2d")` allows developers to draw shapes, lines, text, and images in two dimensions.

## Chart.js Documentation

### What is Chart.js and how can it be brought into your project?
Chart.js is a JavaScript library used to create charts and graphs on web pages. It can be added to a project by linking the Chart.js CDN in the HTML file or by installing it through a package manager like npm.

### List 3 different chart types you can create using Chart.js.
- Bar chart  
- Line chart  
- Pie chart

## Easily Create Stunning Animated Charts with Chart.js

### What are some advantages to displaying data via a chart over a table?
Charts make data easier to understand because they visually show patterns, trends, and comparisons. This helps users quickly see important information instead of reading many numbers in a table.

### How could Chart.js aid your previously created applications visually?
Chart.js could improve applications by turning data into visual charts that are easier to read and more engaging. It can make an application look more interactive and professional.
