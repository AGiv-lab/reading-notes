## CSS Transforms

### What does a CSS transform allow the developer to do?
 **CSS transform** lets a developer *change how an element looks or moves* without changing the page layout.

You can:
- Move it (translate)
- Rotate it
- Resize it (scale)
- Tilt it (skew)

### Example of a transform 
css
.card:hover {
  transform: scale(1.1);

  this makes a card grow slightly when hovered.

Real use on a website:

Product cards that grow when you hover over them

Images that slightly zoom in

Buttons that feel more interactive
}

CSS Transitions & Animations

What does a CSS transition allow the developer to do to an element?

*How does a CSS animation differ from a CSS transition?*
Transition:

-Simple (start → end)

-Needs a trigger (like hover)

-Animation:

-Can have multiple steps (keyframes)

-Can run automatically

-More control and more complex

##8 simple CSS3 transitions that will wow your users-

-Smooth color changes

-Hover scaling (grow/shrink)

-Moving elements slightly

-Fading in/out

-Shadow effects

-Border changes

-Rotations

-Opacity changes
