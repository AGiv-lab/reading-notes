##**HTML Lists, Control Flow with JS, and the CSS Box Model**

*Helps organize content (lists), control how logic works in programs (JavaScript), and understand spacing and layout on a page (CSS Box Model). Together, they make websites structured, readable, and interactive.*

###HTML Lists

-Unordered list (<ul>) — used when item order does not matter (navigation, features, groceries)

-Ordered list (<ol>) — used when order does matter (steps, rankings, instructions)

-Bullet style — can be changed with CSS using list-style-type

-Ordered list numbers — can be changed by:

-Using the type attribute (1, A, a, I)

-Using the start attribute to change starting number


###CSS Box Model

**Box model** — *describes how space is calculated around elements*


  *Box Model Characters (Story Analogy)

  *Content — the main character (text/image)

  *Padding — the personal space around the character

  *Border — the fence around the space

  *Margin — the distance from other characters


**Four Parts of the Box Model**

1.Content — actual text or image

2.Padding — space inside the border

3.Border — edge around padding

4.Margin — space outside the border
