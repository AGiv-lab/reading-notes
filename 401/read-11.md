# Reading: Event Driven Applications

## 1. What native Node.js module allows us to get started with Event Driven Programming?

Node.js provides the built-in **`events`** module.

The `EventEmitter` class allows us to create, listen for, and respond to events.

- `on()` — listens for an event.
- `emit()` — triggers an event.
- `once()` — listens for an event only once.

## 2. What is the value of Object Oriented Programming (OOP) used with Event Driven Programming?

OOP helps organize code into reusable classes and objects.

Combining OOP with Event Driven Programming allows applications to:

- Keep code organized and reusable.
- Separate event handling from other application logic.
- Make applications easier to maintain and expand.

## 3. How would you explain Event Driven Programming on the backend to a non-technical friend?

Event Driven Programming works like a restaurant ordering system.

When a customer places an order, it triggers an event. The kitchen receives the order and begins preparing the food.

Similarly, a Node.js backend can respond to events such as a user signing in, submitting information, or completing a purchase.

The server listens for events and runs the appropriate code when they occur.
