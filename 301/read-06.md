3. Who is Roy Fielding?
-Roy Fielding is one of the creators of the HTTP protocol and the person who helped define REST architecture for web APIs.

4. Why don't the techniques that we use in this class work well when we need to be able to talk to all of the machines in the world?
-The techniques we use in small programs are not always standardized. Computers around the world need a common system and rules so they can communicate consistently.

5. What is the HTTP protocol that Fielding and his friends created?
HTTP is a communication protocol used by the web. It defines how computers send and receive requests and responses over the internet.

6. What does a `GET` do?
-requests are used to retrieve or read data from a server.

7. What does a `POST` do?
-requests are used to send new data to a server and create something new.

8. What does `PUT` do?
-requests are used to completely update or replace existing data on a server

9. What does `PATCH` do?
requests are used to partially update existing data without replacing everything
